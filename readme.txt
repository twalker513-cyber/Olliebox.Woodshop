OLLIE BOX WOODSHOP WEBSITE

How to use this site:

1. Open index.html in a browser to preview it.
2. Replace placeholder product images with real board photos.
3. Replace these placeholder Stripe links inside index.html:
   https://buy.stripe.com/YOUR_PAYMENT_LINK_1
   https://buy.stripe.com/YOUR_PAYMENT_LINK_2
4. Replace youremail@example.com with your real business email.
5. Upload the folder to Netlify, Vercel, or another web host.

Stripe setup:
- Create one Stripe Payment Link for each one-of-one board.
- Set quantity/stock to 1 if available in your Stripe product settings.
- After a board sells, mark the product card as sold or remove it.

Suggested product photo size:
- Use square or 4:3 photos.
- Keep file sizes under 500 KB when possible for faster loading.
